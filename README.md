# Evidence 🔍

**Evidence** is a first-person 3D investigation and deduction game built from the ground up using Python and pure OpenGL. You play as a detective dispatched to a suspect's residence to gather critical evidence regarding a series of murders. To solve the case, you must explore the environment, discover hidden clues, and solve high-stakes interactive puzzles.

This project focuses on a custom graphics pipeline, utilizing direct vertex array rendering to handle complex 3D geometry without the overhead of heavy commercial engines.

## Key Features
* **Immersive Exploration:** A fully 3D environment modeled in Blender and rendered in real-time.
* **First-Person Interaction:** Smooth FPS camera movement and a specialized system for inspecting notes and objects.
* **Environmental Puzzles:** Logic-based challenges including electrical power restoration and safe-cracking mechanics.
* **Optimized Rendering:** Custom `.obj` loader using direct `glDrawArrays` calls for high-performance graphics on integrated and dedicated GPUs.

## Tech Stack
* **Language:** Python 3.10+
* **Graphics API:** PyOpenGL (Direct rendering pipeline)
* **Window & Input:** Pygame 2.6+
* **Math Library:** PyGLM (OpenGL Mathematics for Python)
* **Model Parsing:** PyWavefront
* **Assets:** Blender (Exported as Wavefront .obj/.mtl)

## Installation & Setup

This project uses a Python Virtual Environment (`venv`) to ensure cross-platform compatibility across Windows, macOS, and Linux.

### 1. Prerequisites
Ensure you have the following installed:
* [Python 3.10 or higher](https://www.python.org/downloads/)
* [Git](https://git-scm.com/)
* A C++ Compiler (GCC for Linux, Clang for macOS, or Build Tools for Visual Studio on Windows) – *Required for compiling Pygame if binary wheels are unavailable.*

### 2. Clone the Repository
```bash
git clone [https://github.com/steven-cl/Evidence.git](https://github.com/steven-cl/Evidence.git)
cd Evidence
```

### 3. Create a Virtual Environment
Linux / macOS:

```bash
python3 -m venv .venv
```
Windows:

```dos
python -m venv .venv
```

### 4. Activate the Virtual Environment
Linux (Manjaro/Ubuntu) / macOS:

```bash
source .venv/bin/activate
```
Windows (Command Prompt):

```dos
.venv\Scripts\activate.bat
```
Windows (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install Dependencies
```bash
pip install -r requirements.txt
```

## How to Play
Ensure your virtual environment is active (.venv) before launching:

Linux / macOS:

```bash
python3 main.py
```
Windows:

```dos
python main.py
```

### Controls
W / A / S / D: Movement

Mouse: Look around

Left Click / E: Interact / Inspect clue

ESC: Pause or Exit

## Troubleshooting (Linux & Python 3.14+)
If you are using a Rolling Release distribution like Manjaro or the latest Python 3.14+, you might encounter these issues:

Compilation Delay: If pip stays on Building wheel for pygame... for several minutes, it is normal. It's compiling the C source code for your specific kernel/architecture. Please do not cancel the process.

AVX2 Warning: You may see a RuntimeWarning regarding AVX2 support. This is a performance optimization flag for 2D blitting and will not affect the 3D performance or functionality of this game.

Missing .mtl error: Ensure the .mtl file generated by Blender is in the same folder as the .obj and has the exact name referenced inside the .obj file.

## Developer Notes
Project Architecture: The code is modularized into obj_loader.py (rendering), camera.py (controls), and main.py (game loop).
